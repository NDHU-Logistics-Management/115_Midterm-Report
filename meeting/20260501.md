```r
df_summary() <- df_hualien %>%
    mutate(
        持卡身分分類 = case_when(
            as.character(票種類型) == "4" ~ "普通身分(含TPASS)",
            持卡身分 == "A" ~ "普通身分(含TPASS)",
            持卡身分 == "B" ~ "學生身分",
            持卡身分 == "C01" ~ "敬老優待",
            持卡身分 == "C02" ~ "愛心優待",
            持卡身分 == "D" ~ "員工身分",
            持卡身分 == "C09" ~ "其他優待",
            持卡身分 == "X" ~ "無法區別",
            TRUE ~ NA_character_
        ),
        持卡身分分類 = factor(持卡身分分類, levels = ticket_order)
    )
```

這樣會造成當 票種類型 == "4" 且 持卡身分 == "X" 時，會先命中第一條："普通身分(含TPASS)"。只要 票種類型 == "4"，不管 持卡身分 是 "A"、"B"、"X"，都會被歸到 普通身分(含TPASS)。後面的 "B" ~ "學生身分" 和 "X" ~ "無法區別" 不會生效。

我們不用預設立場："4"(定期票) 一定是 "普通身分(含TPASS)"。
