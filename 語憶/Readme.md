以上file內的圖片，只要以下圖、表：

1. 114年的票種長條圖
2. 增加3年票種比較表，縱軸：票種；橫軸：年份；數值：數量、比例
3. 無須畫各路線的票種長條圖

關於票種長條圖，格式統一為：

1. "票種"正名為"持卡身分"
2. 標題請置左
3. 降冪排序
4. 無須縱軸、橫軸
5. 條狀圖上方，標示比例
6. "普通身分(含tpass)"無須分割出tpass
7. 無法辨識若非零也要放進表及圖

代碼對應名稱也遵從[票證標準說明文件v3.1](https://ticp.motc.gov.tw/motcTicket/):

1. A：普通身分(含TPASS)
2. B：學生身分
3. C01：敬老優待
4. C02：愛心優待
5. C09：其他優待
6. D：員工身分
7. X：無法區別身分
